# Wizz Air ATPL Interview Test

A modern, interactive web-based quiz designed specifically for **Wizz Air** pilot interview preparation. Covers all major **EASA ATPL** subjects with over 200 real-style questions.

## Features

- **Beautiful dark UI** with Wizz Air pink accent
- **200+ ATPL Questions** across 11 subjects
- Fully responsive design (works great on mobile & tablet)
- Select specific topics or take the full test
- Real-time progress bar
- Immediate feedback with correct answers
- Detailed results screen with score and review section
- Shuffle questions for every attempt
- Includes Wizz Air company-specific questions

## Topics Covered

- Air Law (010)
- Aircraft General Knowledge (021)
- Instrumentation (022)
- Mass & Balance (031)
- Performance (032)
- Flight Planning (033)
- Human Performance (040)
- Meteorology (050)
- General Navigation (061)
- Radio Navigation (062)
- Operational Procedures (070)
- Principles of Flight (080)
- Wizz Air Company Information

## How to Use

1. Visit the live site
2. Click **"START EXAM"**
3. Select the topics you want to practice
4. Click **"Begin Test"**
5. Answer the questions and get instant feedback
6. Review your results and weak areas at the end

## Deployment (GitHub Pages)

This project is designed to be deployed easily on **GitHub Pages**:

1. Create a new GitHub repository
2. Upload `index.html` and `README.md`
3. Go to **Settings → Pages**
4. Set source to **Deploy from a branch** → `main` → `/ (root)`
5. Save and wait ~1 minute

Your site will be live at:  
`https://yourusername.github.io/repository-name`

### Custom Domain (Optional)

You can connect your own domain (e.g. `atpl.yourname.com`) via GitHub Pages custom domain settings.
